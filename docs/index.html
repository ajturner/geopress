Put your posts on the map.

GeoPress geotags WordPress posts and pages, embeds interactive maps, and publishes your writing as GeoRSS, KML, and GPX so it shows up in map viewers, Google Earth, and GPS tools.

Why geotag a blog?

Many posts are about a place: a trip, a neighborhood meeting, a field site, a restaurant review. GeoPress records that place once and reuses it everywhere. Readers get a map in the post. Machines get a standard feed they can plot.

  • Your archive becomes a map. One tag shows every located post, so readers can browse by place as well as by date.
  • Open standards, not lock-in. GeoRSS, KML, GPX, and microformats are read by feed readers, Google Earth, QGIS, and GPS devices.
  • Nothing to sign up for. Geocoding uses OpenStreetMap Nominatim and maps default to OpenLayers with OpenStreetMap tiles.
  • Fits how you write. Use the Location box, a shortcode block, an inline tag, or theme template functions.

What it does

One location per post, saved in its own table and reused across maps, feeds, and markup.

Geotag anything

Type a place name, a street address, or [lat, lon], or click the map. Saved locations like “Home” can be reused on later posts.

Interactive maps

Embed a map of one post, a page and its children, or the whole blog. Providers include OpenLayers, OpenStreetMap, Google Maps, and the ArcGIS Maps SDK, which adds web maps and 3D scenes.

GeoRSS feeds

Your Atom, RSS 2.0, and RDF feeds carry each post’s location in Simple, W3C Geo, or GML encoding.

KML and GPX

Open the blog in Google Earth with a self-refreshing NetworkLink, or load posts onto a GPS device as waypoints.

Microformats

Output coordinates, addresses, and place names as geo, adr, and hCard markup that search engines and parsers understand.

Block and Classic editor

The Location box sits in the Gutenberg document sidebar or below the Classic editor. Shortcodes work in any Shortcode block.

…in your feeds, markup and embeds

The same location is published automatically. Pick the format your readers' tools expect, or embed an ArcGIS map.

<item>
  <title>A windy day at the fortress</title>
  <link>https://example.blog/2026/11/fortress/</link>
  <!-- added by GeoPress -->
  <georss:point>60.1454 24.9881</georss:point>
  <georss:featurename>Suomenlinna, Helsinki</georss:featurename>
</item>
<!-- /wp-content/plugins/geopress/wp-kml.php -->
<Placemark id="42">
  <name>A windy day at the fortress</name>
  <styleUrl>#defaultStyle</styleUrl>
  <Point>
    <altitudeMode>relativeToGround</altitudeMode>
    <coordinates>24.9881,60.1454,25</coordinates>
  </Point>
</Placemark>
<!-- INSERT_COORDS, INSERT_ADDRESS, INSERT_LOCATION -->
<div class='geo'>
  <span class='latitude'>60.1454</span>,
  <span class='longitude'>24.9881</span>
</div>
<div class='adr'>Suomenlinna, Helsinki</div>
<div class='vcard'><span class='fn'>Fortress trip</span></div>
<!-- In the post: embed a web map or 3D scene by its portal item ID -->
INSERT_ARCGIS_MAP(41281c51f9de45edaf1c8ed44bb10e30,400,600)

<!-- GeoPress looks up the item type once a day and renders -->
<arcgis-map item-id="41281c51f9de45edaf1c8ed44bb10e30" zoom="11"
            style="height:400px; width:600px;">
  <arcgis-zoom position="top-left"></arcgis-zoom>
  <arcgis-basemap-toggle position="bottom-right"></arcgis-basemap-toggle>
</arcgis-map>
<!-- a Web Scene item renders as <arcgis-scene> instead -->
<?php // single.php, inside The Loop ?>
<?php if ( has_location() ) : ?>
  <p class="post-place">
    Written at <?php echo esc_html( the_location_name() ); ?>
  </p>
  <?php geopress_post_map( 240, 600 ); ?>
<?php endif; ?>

<?php // sidebar.php: every located post, with a list of places ?>
<?php geopress_map( 300, 300, -1 ); ?>
<ul><?php geopress_locations_list(); ?></ul>

GeoRSS encoding is set under GeoPress → Options. The ArcGIS tag works whichever map provider the site uses, and needs no API key for public items.

Install

The defaults work out of the box. There are no accounts to create and no keys to paste.

WordPress6.0+
PHP8.0+
API keysNone
  1. Get the plugin.Download the ZIP and upload it under Plugins → Add New → Upload Plugin, or copy the geopress folder into wp-content/plugins/.
  2. Activate GeoPress.Activation creates the {prefix}_geopress table that stores locations.
  3. Review the options.Optional. Under GeoPress → Options set the map provider, size, zoom, GeoRSS format, and controls. Add a Google Maps key only if you choose Google as the provider.
  4. Geotag a post.In the Location box, type a place, an address, or [lat, lon], or click the map. The location is geocoded when you save.
  5. Show a map.Add INSERT_MAP or a [geopress_post_map] shortcode, or turn on Add Maps to append one to every located post.

Prefer the command line?

# from your WordPress root
git clone https://github.com/ajturner/geopress.git wp-content/plugins/geopress
wp plugin activate geopress

Usage reference

Four ways to place a map, from no code at all to full theme control.

Post content tags

TagOutput
INSERT_MAPInteractive map at the post’s location
INSERT_MAP(h,w)Map with a custom height and width
INSERT_MAP(h,w,url)Map with a KML or GeoRSS overlay
INSERT_GEOPRESS_MAP(h,w)Map of every geotagged post
INSERT_ARCGIS_MAP(id)ArcGIS web map or 3D web scene by portal item ID
INSERT_ARCGIS_MAP(id,h,w)The same, with a custom height and width
INSERT_COORDSCoordinates as a geo microformat
INSERT_ADDRESSAddress as an adr microformat
INSERT_LOCATIONLocation name as an hCard microformat
GEOPRESS_LOCATION(Address)Set the post’s location inline by address
GEOPRESS_LOCATION([lat,lon])Set the post’s location inline by coordinates

Machine tags also work as post tags, for example geo:lat=60.15 and geo:lon=24.94.
